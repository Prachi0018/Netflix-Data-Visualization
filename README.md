# Netflix Data Visualization 

## Project Overview

This project analyzes Netflix content using Python, Pandas, and Matplotlib. The dataset contains information about Movies and TV Shows available on Netflix.

## Objectives

* Load and explore the Netflix dataset
* Clean missing data
* Analyze Movies and TV Shows
* Create data visualizations using Matplotlib
* Understand basic data visualization techniques

## Tools & Technologies

* Python
* Pandas
* Matplotlib
* Jupyter Notebook
* CSV

## Project Files

* `netflix_data_visualization.ipynb` — Jupyter Notebook containing the analysis and visualizations
* `netflix_titles.csv` — Netflix dataset

## Data Cleaning

Missing values are handled using Pandas before performing the analysis.

## Visualization

The project includes a bar chart comparing the number of Movies and TV Shows available in the dataset.

## Future Analysis

The project can be extended to analyze:

* Content by release year
* Top countries
* Popular genres
* Ratings
* Movie duration
* Movies vs TV Shows over time
